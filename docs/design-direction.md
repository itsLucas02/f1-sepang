# SEPANG 56 — Visual & Interaction Direction

## North star

The website must feel **unmistakably Formula 1 / motorsport / racing**.

It should not look like a generic SaaS dashboard with a racing logo pasted on top.

The visual language should communicate:

- Speed
- Precision
- Competition
- Timing
- Grid / track structure
- Race-weekend energy
- Malaysian Sepang identity

The experience should feel modern and premium rather than cartoonish or game-menu heavy.

---

## Visual references to capture conceptually

Use motorsport visual language such as:

- Starting-grid geometry
- Timing tower layouts
- Track-map linework
- Lap counters
- Sector markers
- Grid slots
- Position numbers
- Race-number typography
- Pit-lane / garage labels
- Chevrons and directional motion
- Checkered patterns used sparingly
- High-contrast information hierarchy

Do **not** copy Formula 1's protected brand assets, exact logos, or proprietary typefaces. The site should be F1-inspired, not an imitation of official F1 branding.

---

## Typography

Typography is a major part of the identity.

Recommended system:

- **Display / hero:** wide or extended geometric sans with racing-poster energy
- **UI / body:** highly legible modern grotesk/sans
- **Telemetry / labels:** condensed or mono-style face for small numerical labels, lap counters, rankings, and technical metadata

Typography should use:

- Large numeric hierarchy
- Uppercase labels
- Tight display headlines
- Strong weight contrast
- Tabular numerals where relevant
- Compact telemetry-like microcopy

Avoid generic startup typography where every screen is a centered bold headline over rounded cards.

---

## Layout language

Layouts should feel directional and fast.

Use:

- Asymmetry when useful
- Strong horizontal rails
- Section dividers that resemble timing lines / track markings
- Full-bleed circuit graphics
- Oversized numbers such as `01`, `02`, `56`
- Dense-but-readable race data modules
- Intentional diagonal or forward-moving accents
- Grid structures inspired by starting grids and timing tables

Avoid excessive floating rounded cards and excessive pill-shaped UI.

---

## Color direction

Base should be dark / asphalt / night-race adjacent with bright racing accents.

Potential palette direction:

- Near-black / graphite base
- White / warm white text
- Racing red as primary action accent
- Malaysian-inspired secondary accents used carefully
- Signal colors for states: green, yellow, red

Do not make every element red. Red should carry speed, urgency, CTA, and race-state emphasis.

---

## Motion

Motion should reinforce speed rather than decorate randomly.

Examples:

- Fast directional transitions
- Progress bars resembling lap/timing indicators
- Circuit path drawing on entry
- Leaderboard position movement
- Snap transitions between prediction questions
- Subtle number rolling for scores

Keep transitions short and responsive. Avoid floaty, slow SaaS animations.

---

## Component personality

### Buttons

Sharp or subtly chamfered geometry is preferable to overly soft rounded pills.

### Cards

Use cards when they help comparison, especially driver selection. Avoid making the whole site card-based.

### Driver choices

Driver name, team, strong number/position hierarchy, immediate select state.

### Leaderboard

Should evoke a timing tower / race classification screen rather than a spreadsheet.

### Sepang circuit

The circuit outline should be a signature visual asset throughout the app — hero, guide, progress, and branded moments.

---

## Brand personality

SEPANG 56 should feel:

**Fast. Precise. Competitive. Malaysian. Beginner-friendly.**

Not:

**Corporate. Generic. Childish. Overly technical.**

---

## Design rule for coding agents

Before implementing a page, ask:

> “If the SEPANG 56 logo disappeared, would this still look like a racing/F1 experience?”

If the answer is no, the visual design is too generic.
