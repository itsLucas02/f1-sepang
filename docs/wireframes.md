## UX rules

- One learning concept per screen.
- One prediction question per screen.
- Never assume the user understands F1 shorthand.
- Authentication should not block discovery or learning.
- Mobile experience must remain first-class.
- Avoid dashboard overload. The product should feel fast, direct, and race-like.
